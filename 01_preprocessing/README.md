# Preprocessing Pipeline

This directory contains all preprocessing steps required to prepare the MERFISH data for downstream analysis. The pipeline is structured into three main stages:

---

## 1. Run Baysor on Transcript Outputs

The first step is to apply **Baysor** to the transcript outputs generated by the MERSCOPE platform. This step segments individual cells from the spatial transcriptomics data.

To run Baysor on a SLURM-based computing cluster, use the following command:

```bash
sbatch 01_baysor_run.sh
```

> This will generate one `.loom` file per brain processed.

---

## 2. Merge Baysor Outputs

Once Baysor has completed, the `.loom` files (one per brain) are combined into a single dataset using:

- **Notebook:** `02_Load_and_concat_baysor.ipynb`

This step loads the individual segmentations and concatenates them into a unified dataset for downstream processing.

---

## 3. Microglia Segmentation via Otsu Thresholding

The final preprocessing step applies **Otsu segmentation** to max-projected microglia images in order to estimate rough spatial coverage.

Run this step on a SLURM cluster using:

```bash
sbatch 03_rough_mic_seg.sh
```

- **Script Driven:** `microglia_segmentation.py`

The `.sh` file handles job submission and environment activation, while the Python script performs the segmentation logic.

---

## Notes on Resource Requirements

- **Memory:** The default job configuration requests **250 GB of RAM**, which is suitable for large whole-brain sections. For smaller regions, considerably less memory may be required.
- **CPUs:** A **16-core CPU** setup should be sufficient for most cases.

Adjust SLURM parameters based on your dataset size and available hardware.

---

## Summary

| Step                        | Script / Notebook                 | Output                |
|-----------------------------|-----------------------------------|------------------------|
| Baysor Segmentation         | `01_baysor_run.sh`                | Individual `.loom` files |
| Combine Loom Files          | `02_Load_and_concat_baysor.ipynb` | Merged dataset         |
| Microglia Image Segmentation| `03_rough_mic_seg.sh` → `microglia_segmentation.py` | Segmentation masks      |

Ensure that each job is run using the appropriate environment as described in the [`Environments/`](../Environments) directory.
